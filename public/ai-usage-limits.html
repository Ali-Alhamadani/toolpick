How much do you use it?

Claude · every day for work

Pro · $20/mo ($17/mo billed yearly)

Claude's own page calls Pro the plan “for everyday work”.

  • What you get: At least 5x more usage per 5-hour session than Free, plus a weekly limit; includes Claude Code
  • Limit resets: A rolling 5-hour session window on every plan, plus a weekly limit on paid plans. Ultra has no 5-hour limit for verified accounts.
  • If you hit the limit: Wait for your limit to reset; move to a higher plan; on paid plans, turn on usage credits to keep working at standard API rates.
  • Next step up: Max ($100/mo)

Tips to make a limit last longer

  • Start a new chat for a new topic. Claude and Gemini both count long chats as more usage.
  • Use the lighter model for simple jobs. Gemini, Windsurf and Cursor all say the model you pick changes how fast you use your allowance; ChatGPT's Fast mode uses it 2.5x faster.
  • Check the meter. Claude: Settings › Usage. Gemini: Settings › Usage Limits. Microsoft: Services & subscriptions.
  • Paying for two? If you only hit limits on one tool, upgrade that one and drop the other. Audit what you pay →

FAQ

Does ChatGPT, Claude or Gemini have a fixed number of messages?

Mostly no. Claude and Gemini count usage by how much work a request takes (chat length, files, model), so there's no fixed message count. ChatGPT says everyday text chats are unlimited on every plan, with separate limits for uploads, images, deep research, Thinking and Codex. GitHub Copilot is the clearest: a set number of AI credits a month (1,500 on Pro).

Which AI limits reset every 5 hours?

Claude (a rolling 5-hour session plus a weekly limit), Google Gemini (every 5 hours until a weekly limit) and ChatGPT's Codex and Work on Plus (5 hours plus weekly). Cursor resets weekly, Windsurf daily and weekly, and GitHub Copilot monthly on the 1st (00:00 UTC). Checked 2026-11-03.

What happens when I hit my Claude limit?

Claude says you can wait for it to reset, move to a higher plan, or on paid plans turn on usage credits to keep working at standard API rates. Claude Code uses the same limit as chat.

Is Claude Max or ChatGPT Pro worth it for heavy use?

Both start at $100 a month. Claude Max gives 5x Pro usage every 5 hours and every week. ChatGPT Pro 100 adds Pro reasoning and removes the 5-hour limit in Codex and Work. If you mostly code with agents, compare them with Cursor Super ($100, 15x Plus) and GitHub Copilot Max ($100, 20,000 AI credits).

Can I pay for extra usage instead of upgrading?

Claude (usage credits at API rates on paid plans), GitHub Copilot ($0.01 per AI credit with a budget you set), Cursor (top-offs), Windsurf (extra usage at API pricing) and ChatGPT (credits for Codex, Work and Office add-ins) all say yes. Gemini's limits page doesn't mention a top-up. Mistral and Microsoft don't say.

How did you pick the plan for each use level?

From each company's own wording where it gives one (Claude: Pro “for everyday work”, Max “for all-day work”; Cursor recommends Premium for new AI users and Super for daily agent users; GitHub calls Pro+ ideal for AI power users), otherwise from the allowances each plan states. We don't guess message counts the companies don't publish.

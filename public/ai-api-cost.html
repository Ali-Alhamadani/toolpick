How we work it out

  • Prices: copied from each official API pricing page on 2026-11-05, before tax. Nothing is estimated.
  • Math: monthly cost = (input MTok × $/MTok in) + (output MTok × $/MTok out).
  • Tier: Standard / paid-tier list rates only. Batch, priority, flex, and prompt-cache writes are listed under Left out.
  • Promos: where Google shows a promo end date, we use the current promo rate and note the later price on the card.
  • Not included: tools (web search, grounding), image/audio specialty rates, committed-use discounts, and tax.

FAQ

What will the OpenAI / Claude / Gemini API cost for my usage?

Multiply your monthly input MTok by each model's input $/MTok, add monthly output MTok × output $/MTok. Example: 10M in + 2M out on Claude Sonnet 5.5 is 10×$2 + 2×$10 = $40/mo. Checked 2026-11-05.

Which API is cheapest right now?

At equal token volume, the lowest Standard rates we verified are OpenAI GPT-6 Luna and Anthropic Haiku 5.5 (≤100K prompts), both $0.10/MTok in and $0.50/MTok out, then Gemini 3.1 Flash-Lite at $0.25/$1.50. Flagship models (GPT-6 Astra, Fable 5.1) are $10/$50. Checked 2026-11-05.

Do these prices include prompt caching or batch discounts?

No. The calculator uses each provider's standard paid input and output token rates only. Anthropic lists prompt-cache read/write and 50% batch; OpenAI lists cache writes and Batch/Fast/Ultrafast; Gemini lists Batch/Flex/Priority. Those can change the bill.

What is an MTok?

One MTok is 1 million tokens. Providers price API use per million input tokens and per million output tokens. A short chat turn is often a few thousand tokens; a RAG pipeline that stuffs big contexts can burn millions of input tokens a month.

Why is openai.com/api/pricing not your OpenAI source?

That URL currently shows ChatGPT Business and Enterprise seat plans, not API token rates. Token rates are on platform.openai.com/docs/pricing, which is what we checked.

Are free tiers included?

Gemini's Free Tier shows free input/output for some Flash models with limits; OpenAI and Anthropic API usage is pay-as-you-go (Claude chat Free is a product plan, not these API rates). The cards show paid Standard rates so you can budget production traffic.

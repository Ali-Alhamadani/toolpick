Could it be $0?

If your use is light, try the free plan first:

  • Cursor: Free $0: limited AI usage, agent and chat requests
  • GitHub Copilot: Free $0: 2,000 code completions a month, limited chat and agent usage
  • Claude Code: Free $0, but Claude Code isn't included
  • Windsurf: Free $0: light agent quota, unlimited Tab completions
  • Warp: Free $0: modern terminal; buy agent usage or bring your own AI

How we work it out

  • Prices: copied from each official pricing page on 2026-11-04, before tax. Nothing is estimated.
  • Which plan: Light = the cheapest paid plan. Daily and Heavy follow each company's own wording about who a plan is for (the same picks as our AI usage limits guide). You can change the plan on any card.
  • Teams: 2 or more people use each company's team plan unless you choose individual plans. Seat limits and flat team fees are applied.
  • Yearly: used only where the page shows a yearly price; otherwise the monthly price is used and the card says so.
  • Not included: extra usage you buy on top (API-rate top-ups, credits) and tax.

FAQ

What's the cheapest AI coding tool for one developer?

For light use, Cursor Plus at $8 a month is the cheapest paid plan, but it only has Grok models. GitHub Copilot Pro is $10 a month with unlimited completions and $15 of AI credits. GitHub Copilot, Cursor, Windsurf and Warp also have $0 plans with limited usage. Checked 2026-11-04.

How much does Claude Code cost?

Claude Code comes with Claude Pro ($20 a month, or $17 a month billed yearly at $200 up front), Max ($100) and Ultra ($200). The free Claude plan doesn't include Claude Code. Teams pay $25 per standard seat a month ($20 billed yearly) or $125 per premium seat ($100 billed yearly).

What does GitHub Copilot cost for a team?

Copilot Business is $19 per user a month and Enterprise is $39 per user a month, from GitHub's plans page. For a team of 10 on Business that's $190 a month, or $2,280 a year.

How is Windsurf's team price worked out?

Windsurf Teams is a flat $80 a month for the team plan plus $40 a month for each full dev seat, up to 200 users. So 5 developers cost $80 + 5 × $40 = $280 a month. windsurf.com/pricing now opens Devin's pricing page, which lists these plans.

Is yearly billing cheaper?

Where the official page shows a yearly price, yes: Claude Pro is $17 instead of $20, Claude Team $20 instead of $25 per seat, Warp Build $18 instead of $20, Warp Max $180 instead of $200 and Warp Business $45 instead of $50. Cursor, GitHub Copilot and Windsurf don't show a yearly price on their pricing pages, so the calculator uses their monthly price.

Why don't you compare how much usage each plan gives?

Each company counts usage differently: Cursor in multiples of its Plus plan, GitHub in AI credits, Claude in multiples of Pro per 5 hours and week, Warp in dollars of agent usage, Windsurf in quotas it doesn't number. We show what each page says is included rather than guess an exchange rate.
